# Support

[简体中文](SUPPORT_ZH.md)

For product documentation, start with the Waveshare documentation linked from `README.md`.

For repository issues, open a GitHub issue with:

- the affected example or file path,
- ESP-IDF or Arduino version,
- reproduction steps,
- expected behavior,
- actual behavior,
- relevant logs or screenshots.

Also include the board hardware revision when known, the exact example path, and
whether the observation used a source-built CI artifact or the factory image.

For order-specific hardware support, contact Waveshare support with the product model and order information.
